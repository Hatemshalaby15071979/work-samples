# Working samples

Scratch work samples, proposals, spikes, and tooling snippets kept together for
reference. Each sub-directory is an independent sample:

* `proposal-work-sample/` — proposal, estimate, and supporting notes.
* `rag-work-sample/` — a RAG support-assistant sample (Python, pydantic) with
  tests, Dockerfile, and `run_eval.py`.
* `sql-work-sample/` — SQL query samples with expected outputs and `run_checks.py`.
* `tooling/` — small helper scripts.

These are reference samples, not a shippable product. Treat each folder
individually; there is no single installable package at this level.
